# Daily

### Qu'est ce que le dossier Daily ?

!!! info
    Le dossier **Daily** regroupe les notes quotidiennes, les journaux de travail, les suivis de tâches, les idées rapides et les éléments temporaires à traiter ou à classer ultérieurement.
    Il constitue un espace de capture rapide : une information peut y être ajoutée immédiatement sans devoir déterminer son emplacement final. Les notes importantes peuvent ensuite être déplacées ou transformées en documentation durable dans les dossiers correspondant.

### Pourquoi ce dossier ?

!!! info
    Le principal objectif est de réduire la perte d’information. Lorsqu’une commande fonctionne, qu’un incident est résolu, qu’une idée de projet apparaît ou qu’une tâche doit être suivie, il est souvent plus efficace de la noter immédiatement dans une page quotidienne.
    Ce dossier permet aussi de conserver un historique des activités : travaux réalisés, problèmes rencontrés, décisions prises, temps consacré à un projet, apprentissages et prochaines actions, tout en leur attribuant un timestamp.
