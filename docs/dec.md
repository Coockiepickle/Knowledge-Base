# DEC Techniques de l’informatique

### Qu'est ce que le dossier DEC Techniques de l'informatique ?

!!! info
    Le dossier **DEC Techniques de l’informatique** rassemble l’ensemble des contenus que j'ai effectué lors de mon année au Québec. Il regroupe les cours, exercices, travaux pratiques, projets, révisions et ressources acquises durant cette formation.

### Pourquoi ce dossier ?

!!! info
    Ce dossier permet de préserver une base de connaissances structurée issue des fondamentaux de la formation québécoise. Même après la fin du cursus, ces contenus peuvent être utiles pour retrouver une notion, réutiliser un exercice, comparer une ancienne méthode ou consolider des bases techniques.
