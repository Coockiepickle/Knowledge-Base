# General

### Qu'est ce que le dossier General ?

!!! info
    Le dossier **General** contient la documentation technique transverse qui ne dépend pas directement d’une formation, d’un projet académique spécifique ou d’un suivi quotidien.
    Ce dossier peut couvrir aussi bien l’administration système que le développement, le réseau, la cybersécurité, le self-hosting ou les outils de productivité.

### Pourquoi ce dossier ?

!!! info
    Certaines connaissances restent pertinentes indépendamment d’un cursus ou d’un projet particulier. Centraliser ces contenus dans un dossier général évite la duplication et facilite leur réutilisation.
    Par exemple, une procédure d’installation de Docker, une configuration Nginx, une fiche sur Git ou une documentation de VLAN peut être utile pour un projet personnel, une mission professionnelle ou un travail académique. Le dossier `General` devient ainsi une bibliothèque technique de référence.
